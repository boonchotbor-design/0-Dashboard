1 ภาพรวม Tech Stack

🖥️ Next.js 16

Framework หลัก รองรับ Server-Side Rendering และ App Router

⚛️ React 19 + TypeScript

UI Library พร้อม Type Safety ช่วยลด Bug ระหว่างพัฒนา

🎨 Tailwind CSS v4

Utility-first CSS Framework ตกแต่ง UI ได้รวดเร็วมาก

📊 Recharts + shadcn/ui

Library สำหรับ Chart และ Component UI สำเร็จรูปพร้อมใช้

🐙 GitHub

เก็บโค้ด + Version Control + ทำงานร่วมกับทีม

▲ Vercel

Host เว็บไซต์ ฟรี + Auto Deploy ทุกครั้งที่ Push โค้ด

เหตุผลที่เลือก Stack นี้รายละเอียด
ฟรีGitHub + Vercel มี Free Tier ใช้ได้จริงในงาน Production
เร็วAuto Deploy ทุกครั้งที่ Push โค้ด ไม่ต้องทำด้วยตัวเอง
ง่ายไม่ต้องตั้งค่า Server เอง Vercel จัดการให้ทั้งหมด
Professionalใช้ใน Production จริงทั่วโลกโดยบริษัทชั้นนำ

2 ติดตั้ง Program ที่จำเป็น

2.1 Node.js — ต้องทำก่อนสุด

Node.js คืออะไร? คือตัวที่ทำให้เครื่องของเราสามารถรัน JavaScript และจัดการ package ต่างๆ ได้

  1. ไปที่ https://nodejs.org ดาวน์โหลด LTS Version (ปุ่มสีเขียว)
  2. ติดตั้งตามปกติ กด Next → Next → Install ตลอด
  3. เปิด PowerShell ตรวจสอบ: 
    node --version    # ควรได้: v20.x.x หรือสูงกว่า
npm --version     # ควรได้: 10.x.x หรือสูงกว่า
✅
ถ้าได้ตัวเลข Version แสดงว่าติดตั้ง Node.js สำเร็จแล้ว

2.2 Git — Version Control

Git คืออะไร? คือตัวที่ช่วยติดตามการเปลี่ยนแปลงของโค้ด และส่งโค้ดไปยัง GitHub

  1. ไปที่ https://git-scm.com/downloads ดาวน์โหลด Windows version
  2. ติดตั้ง กด Next ตลอด ใช้ default settings
  3. ตรวจสอบ: git --version → ควรได้ git version 2.x.x

2.3 VS Code — Code Editor

VS Code คืออะไร? โปรแกรมสำหรับเขียนโค้ด ฟรี รองรับ TypeScript และ React ได้ดีมาก

  1. ไปที่ https://code.visualstudio.com ดาวน์โหลดและติดตั้ง
  2. กด Ctrl+Shift+X ติดตั้ง Extensions:
    ESLint Prettier Tailwind CSS IntelliSense GitLens Auto Rename Tag

2.4 Vercel CLI (เสริม)

npm install -g vercel
vercel --version

3 ตั้งค่า GitHub

3.1 สมัครบัญชี GitHub

  1. ไปที่ https://github.com กด Sign Up
  2. ใส่ Email + Password + Username → ยืนยัน Email
  3. เลือก Free Plan

3.2 เชื่อม Git กับ GitHub บนเครื่อง

git config --global user.name "ชื่อของคุณ"
git config --global user.email "email@example.com"
git config --list   # ตรวจสอบ

3.3 สร้าง Repository ใหม่

  1. กด "+" มุมบนขวา → New repository
  2. ตั้งชื่อ: my-dashboard → เลือก Public → ไม่ต้องติ๊ก Initialize with README
  3. กด Create repository

4 สร้างโปรเจกต์ Next.js ใหม่

4.1 สร้างโปรเจกต์

cd C:\Users\[ชื่อUser]\Desktop
npx create-next-app@latest my-dashboard
💡
ตอบคำถาม: TypeScript → Yes | ESLint → Yes | Tailwind CSS → Yes | src/ directory → Yes | App Router → Yes | Turbopack → No | Customize alias → No

4.2 เปิดและรันโปรเจกต์

cd my-dashboard
code .          # เปิด VS Code
npm run dev     # รัน Dev server → เปิด http://localhost:3000

4.3 ติดตั้ง Libraries ที่จำเป็น

npm install recharts
npm install lucide-react
npm install class-variance-authority clsx tailwind-merge
npm install jspdf html2canvas xlsx

4.4 ติดตั้ง shadcn/ui

npx shadcn@latest init
npx shadcn@latest add card button badge separator dropdown-menu

5 โครงสร้างโปรเจกต์ที่ถูกต้อง

my-dashboard/
├── src/
│   ├── app/
│   │   ├── layout.tsx       ← Layout หลัก (ทุกหน้าใช้ร่วม)
│   │   ├── page.tsx         ← หน้าแรก (/)
│   │   └── globals.css      ← CSS Global
│   ├── components/
│   │   ├── ui/              ← shadcn components (อย่าแก้)
│   │   ├── charts/          ← Chart components ต่างๆ
│   │   └── dashboard/       ← KPICard, Sidebar, Header
│   ├── data/
│   │   └── dashboardData.ts ← ข้อมูลทั้งหมด (แก้ตรงนี้)
│   └── lib/
│       └── utils.ts         ← Helper functions
└── public/                  ← รูปภาพ, โลโก้, ไฟล์ static
ไฟล์/โฟลเดอร์หน้าที่
src/app/page.tsxหน้าหลัก — แก้ตรงนี้เพื่อเพิ่ม/ลด Section
src/components/Component ย่อยๆ ที่ใช้ซ้ำได้
src/data/ข้อมูลทั้งหมด — แยกออกจาก UI
public/รูปภาพ, โลโก้, ไฟล์ download

6 Deploy บน Vercel

6.1 Push โค้ดขึ้น GitHub

cd C:\path\to\my-dashboard
git init
git add .
git commit -m "🎉 Initial commit: Dashboard project setup"
git remote add origin https://github.com/[username]/my-dashboard.git
git push -u origin main

6.2 สมัคร Vercel และ Deploy

  1. ไปที่ https://vercel.com → Sign Up with GitHub
  2. กด Add New Project → เลือก Repository my-dashboard
  3. กด Deploy (Vercel ตั้งค่าอัตโนมัติ) → รอ 2-3 นาที
  4. ได้ URL: my-dashboard.vercel.app ✅
🚀
Auto Deploy! ทุกครั้งที่ Push โค้ด Vercel จะ Deploy ให้อัตโนมัติ ภายใน 1-2 นาที

6.3 Workflow หลัง Deploy

git add .
git commit -m "✨ เพิ่ม Chart ยอดขาย"
git push
# → Vercel Deploy อัตโนมัติ!

10 Troubleshooting ปัญหาที่พบบ่อย

❌ node_modules หาย / npm run dev Error

Error: ENOENT: no such file or directory

npm install
npm run dev

❌ Port 3000 ถูกใช้งานอยู่

Error: EADDRINUSE :::3000

npm run dev -- -p 3001

❌ TypeScript Error

Error: Type 'string' is not assignable to type 'number'
แก้ไข: ใช้ Number(value) หรือ parseInt(value)

❌ git push Authentication Error

GitHub → Settings → Developer settings → Personal access tokens → Generate token → ใช้ Token แทน Password

❌ Vercel Build Failed

Vercel Dashboard → Project → Deployments → คลิก Failed → ดู Build Logs → แก้โค้ด → Push ใหม่

❌ Chart ไม่แสดงผล

// ✅ ต้องมี ResponsiveContainer + parent ที่มี height:
<div style={{ width: '100%', height: 300 }}>
  <ResponsiveContainer width="100%" height="100%">
    <BarChart data={data}>...</BarChart>
  </ResponsiveContainer>
</div>
